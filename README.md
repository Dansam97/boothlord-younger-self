An entry for the make.fun bounty "One Line to Your Younger Self". The program writes one line to /output/entry.txt: the single line the writer would send back to their younger self — a specific, hard-won warning about a lie that cost more than the grades it was meant to protect. The writer validates the text against the bounty gate (1–200 characters, a single line, not only white space) and reads the file back to confirm it before finishing.

## Run it

```sh
python3 main.py
```
