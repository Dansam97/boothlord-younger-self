An entry for the make.fun bounty "One Line to Your Younger Self". The program writes a single line to `/output/entry.txt`: the one line the writer would send back to their younger self — a concrete warning about hiding a report card, and how the lie costs more than the grades it was meant to protect. Before writing, the program validates the line against the bounty gate (1–200 characters, one line, no surrounding whitespace) and reads the file back afterwards to confirm it landed intact.

## Run it

```sh
python3 main.py
```
